01. INDUSTRY CONTEXT & PROBLEM STATEMENT

The Job Search Gatekeeper Problem

1. Automated Screening ATS Gatekeeping

Over 75% of resumes are filtered out by Applicant Tracking Systems (ATS) on keyword matching before any human recruiter reads them.

2. The Time Barrier Slow Manual Tailoring

Manually rewriting a resume for each specific job description works best but takes 30–60 minutes per application, creating a severe bottleneck.

3. The Skill Barrier Raw AI Flaws

General-purpose chatbots (like raw ChatGPT) produce inconsistent, unguided outputs, demand prompt skills, and dangerously fabricate experience.

Target Persona: "Arjun" (The Competent Middle Candidate)

Capable professionals who interview well once reached, but lack prompt engineering skills and are blocked by the time-and-skill barrier of automated screening.

Viva Script: Capable job seekers fail not because they lack skills, but because generic resumes fail initial ATS screens. Manual tailoring works but is too slow. Raw AI tools demand high prompt skills and fabricate fake experience. RoleFit AI targets the "competent middle" applicant.

02. PROJECT OBJECTIVES & CORE PHILOSOPHY

Engineered Workflow with Ethical Design

Core Engineering Objectives

  • Full-Stack Web App: Guided single-page experience (React + Node + MongoDB).
  • Secure AI Proxy: Google Gemini accessed strictly via backend proxy (zero API key exposure).
  • Deterministic ATS Check: Transparent, reproducible keyword score without AI hallucination.
  • PDF & Resume Management: Live preview, inline editor, ownership-checked persistence, clean PDF export.

Core Product Philosophy

  • AI as a Building Block: AI is one swappable component inside a structured workflow, not the product itself.
  • No-Fabrication Ethics: Distinguishes safe generic terms from genuine skill gaps; encourages learning rather than faking.
  • Customer Value Focus: Measured by time saved and interview callback improvements rather than AI novelty.
Viva Script: Our philosophy treats AI as a swappable backend component rather than the product. We enforce a strict "No Fabrication" rule: users can insert safe domain buzzwords, but real technical skill gaps are marked non-addable with recommended courses instead.

04. SYSTEM DESIGN & ARCHITECTURE

Three-Tier Client-Server Architecture

Presentation Tier Client Side (React + Vite)

Single-Page Application rendered with Vite. Features responsive dark-glassmorphism UI, inline resume editor, live PDF preview, and dynamic ATS dashboard.

Application Tier Server Side (Node + Express)

Holds business logic, JWT auth, input validation, defensive JSON parsing, and a secure backend proxy to Google Gemini API (protecting secrets).

Data Tier Persistence & Services

MongoDB Atlas (via Mongoose) stores ownership-scoped user accounts & resumes. Reaches Google Gemini AI via backend SDK.

Data Flow: Client (JWT Header) ➔ Express Routes ➔ Gemini Proxy (JSON Schema) ➔ Response ➔ Dynamic React UI Update
Viva Script: The application uses a classic 3-tier architecture. React Vite SPA on the frontend, Node.js Express API on the backend, and MongoDB Atlas for data persistence. The Gemini API key is isolated strictly within backend environment variables.

05. SYSTEM IMPLEMENTATION

Core System Modules

1. Auth & Session

Email/Password registration with bcrypt hashing + Google Identity Services OAuth. Protected API routes use JWT Bearer authentication middleware.

2. Profile & Resume Upload

Supports manual profile text or multi-format file uploads (PDF, DOCX, TXT) parsed in-memory using pdf-parse and mammoth.

3. AI Tailoring Engine

Engineered system prompt requesting strict JSON. Returns tailored sections plus transparent "tailoring notes" explaining modifications made.

4. ATS & Skill-Gap Engine

Parses job descriptions into 3-tier keywords: Matched (Green), Safe-to-Add Generic (Yellow), and Skill Gaps (Red) with course links.

5. Editor & Live Preview

Interactive single-page workspace with inline text editing and real-time styled PDF preview syncing immediately with state.

6. Persistence & Export

Saves ownership-validated resumes in MongoDB Atlas. Exports clean single-column PDFs using custom CSS @media print rules.

06. MODULE DEEP DIVE — AI TAILORING

Robust AI Proxy & Prompt Engineering

Prompt Engineering Principles

  • Zero-Fabrication Mandate: Explicitly forbids adding skills, companies, or credentials not in the candidate profile.
  • JSON Schema Enforcement: Forces output into strict JSON structure containing tailored sections and tailoring notes.
  • Keywords Contextualization: Embeds extracted JD keywords into experience bullet points naturally.

Backend Proxy Resilience

  • API Key Security: Secrets stored in server environment variables (never sent to client).
  • Defensive Parsing: Sanitizes markdown JSON wrappers before JSON.parse() to prevent server crashes.
  • Network Retry Logic: Automatic retry on intermittent corporate proxy timeouts.
  • Swappable Model Architecture: Model name configured via env variables (`gemini-2.5-flash`).
Viva Script: In our AI Tailoring module, we engineered system prompts that enforce zero fabrication and strict JSON output. The backend handles defensive JSON cleaning, network retries, and swappable model configuration.

07. MODULE DEEP DIVE — ATS ENGINE

3-Tier Keyword & Skill-Gap Classification

MATCHED (Green) Existing Alignment

Keywords and technical skills from the JD that are already present in the candidate's resume (e.g., Product Strategy, User Research, Mixpanel).

SAFE TO ADD (Yellow) Click to Auto-Insert

Generic domain terms, soft methodologies, or industry buzzwords missing from the resume. Candidates can click a chip to auto-insert it at their cursor position.

SKILL GAPS (Red) Learn, Don't Fake

Hard technical skills & specialized frameworks missing (e.g., LLMs, Machine Learning). Non-addable in UI; hovering reveals course learning links (Udemy, Coursera).

Explainable Scoring: Score = (Matched Keywords / Total JD Extracted Keywords) × 100. Scores are 100% reproducible and transparent.
Viva Script: Our ATS check categorizes terms into 3 groups. Matched terms in green, safe domain terms in yellow (click to insert), and hard skill gaps in red. Hard skill gaps cannot be clicked; hovering reveals direct learning links to Coursera and Udemy.

08. ENGINEERING CHALLENGES & SOLUTIONS

Real-World Problem Solving

1. Corporate Network DB Block

Challenge: MongoDB Atlas cloud port blocked on corporate network.
Solution: Developed locally with local MongoDB instance during dev, then migrated smoothly to MongoDB Atlas for cloud deployment.

2. AI Model Deprecation

Challenge: Configured Gemini model version retired by API provider.
Solution: Leveraging swappable model configuration architecture, pinned to gemini-2.5-flash with zero frontend code changes.

3. Mobile UI Overlap & ESM Vercel Deployment

Challenge: Mobile header text collision and Vercel ESM ERR_REQUIRE_ESM serverless module error.
Solution: Added responsive CSS media queries, created root package.json with "type": "module", and dynamic import() in api/index.js.

4. Guarding Anti-Fabrication

Challenge: Preventing users from pasting unearned skills into resume.
Solution: Created getManualSkillsAdded() check to warn users if unacquired skill gaps are pasted into the editor.

Viva Script: During development, we solved real production challenges: corporate firewall DB blocks, AI model deprecation, ESM serverless deployment on Vercel, and enforcing anti-fabrication UI guards.

10. KEY INFERENCES & LEARNINGS

Major Takeaways from Project

1. Problem Framing > Raw Tech

Grounding the project in a specific user archetype ("Arjun", the competent applicant who cannot prompt AI) produced a much sharper, defensible product than a generic AI tool.

2. Engineering Surrounds the AI

Reliability comes from system engineering — strict JSON contracts, secure proxies, and defensive fallback parsers — rather than trusting the AI model alone.

3. Transparency Builds User Trust

A deterministic, reproducible ATS keyword score is far more trustworthy to job seekers than an opaque, hallucinated AI score.

4. Ethical Design is a Feature

Treating anti-fabrication as a feature (distinguishing safe terms from skill gaps and offering course links) transformed an ethical constraint into a key value proposition.

Viva Script: Key learnings: Problem framing matters more than raw technology; reliable software engineering must surround AI models; and ethical design principles can be transformed into compelling product features.
