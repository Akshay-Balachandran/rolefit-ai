⚖️ Why Alternative Tools Were Rejected

Server-Side Express Proxy vs. Client-Side Gemini

Rejected Client-Side API: Exposes Gemini API keys in browser network requests. Express Proxy isolates key in server environment variables and enables JSON sanitization.

Node Fetch + Gemini Scraper vs. Puppeteer / Selenium

Rejected Puppeteer: Heavy 300MB headless Chromium binary fails on Vercel serverless limits. Fetch + Gemini AI strips ads and cookie popups dynamically.

In-Memory RAM Buffer vs. Disk File Uploads

Rejected Local Storage: Saving resumes on server disk creates privacy vulnerabilities. `memoryStorage` processes buffers in RAM and discards them immediately.

Native @media print vs. jsPDF / html2canvas

Rejected jsPDF: Canvas rasterization converts text into flat pixel images, rendering PDFs unreadable by ATS scanners. Native print generates vector PDFs with selectable text.
